## Pesquisa

Na minha pesquisa do PIBIC-EM, analisei **24 Projetos Pedagógicos de Curso de seis Institutos Federais da Região Sul** para entender como a ERER aparece nos currículos.

| Etapa | Ferramentas |
|-------|-------------|
| Mineração de texto no corpus | AntConc |
| Organização e tabulação dos dados | Google Planilhas |
| Tratamento estatístico e gráficos | R |
| Noções de programação | Python |

- Apresentei os resultados no **XIV COPENE** (Congresso Brasileiro de Pesquisadores/as Negros/as, UnB, 2026) e no **SEPEI** (Seminário de Ensino, Pesquisa, Extensão e Inovação do IFSC).
